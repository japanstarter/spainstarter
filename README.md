# SpainStarter (spainstarter.com)

Calm, practical travel planning for Spain — AVE high-speed trains, regional itineraries, tapas & culture, and all 8,124 Spanish municipalities.

- **Country:** Spain (España)
- **Complete Municipality Coverage:** All **8,124** official cities, towns, and municipalities across **19** regions
- **Multi-Language Support:** 9 languages (`en`, `de`, `fr`, `es`, `it`, `nl`, `ja`, `ko`, `zh-tw`) with full `hreflang` alternates
- **Interactive Tools:** 14 client-side travel planning calculators & generators
- **Build:** Zero-dependency Node.js static & edge build (`node build.mjs`)
